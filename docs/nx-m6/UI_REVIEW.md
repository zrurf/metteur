# 新增界面复核记录

预览对应的是七个范围，并非必须七个独立导航页：PV06 为 Addon 宿主，PV07 为其中的检查页面。

| 范围 | 本轮实际复核 | 修正 / 结论 |
|---|---|---|
| PV01 项目记忆 | 空态、真实本地样例、来源/摘要/文件、390px 窄视口 | 去掉嵌套 main 语义；空态说明改为准确的 chat 保存入口；来源不冒充验证 |
| PV02 Prompt 资源 | Project/Personal 切换、本地项目 Prompt、版本与操作入口 | 去掉嵌套 main；空的个人库不会混入项目记录 |
| PV03 任务续跑 | 列表空态、创建表单、限制/确认/禁用按钮、关闭行为 | 保留已认可结构；不为外观改动运行权限 |
| PV04 调度 | 无任务空态、创建表单、时区/规则、未选任务不可提交、Escape 恢复焦点 | 宿主不会暗中创建另一个任务 |
| PV05 蓝图交接 | 实际本地模型提案，概览/版本/交接三个区，拒绝入口 | 修正等待人工审批却显示模型慢的文案；Addon 行隐藏冗长工作区前缀，完整摘要仍在 manifest |
| PV06 插件宿主 | M5 实际签名样例和禁用撤销；M6 能力说明复核 | 能力标识换成清晰语句；实际隔离/撤销证据沿用 M5 |
| PV07 检查与成果验收 | M5 正常诊断与独立验收，M6 入口/边界文字复核 | 源码诊断与缺失的视觉/模型证据明确分开 |

前期批准均保留原范围。此轮只进行内部修正和轻微文字/布局整理，没有把新功能冒充已获预览批准。最终“所有新页面美术定稿”仍需要用户确认。

本轮本地提案夹具只对成功执行有终止分支；拒绝后它重复提案，实际系统在重复工具调用保护处停止。保留该失败记录，归类为夹具场景缺口，不把它计为成功拒绝后的模型行为，也不修改用户授权来绕过保护。

窄视口为 Chromium 内390×844 CSS像素的独立复核容器，不是原生移动端或跨浏览器矩阵。一次全页截图超时后改用当前视口截图，保留真实观察边界。
