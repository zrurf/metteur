# 宿主确认的界面位置

2026-10-22；源码基线 773810b 加本功能差异，提交前摘要 view-source-before-commit.json。复用 Recovery 的 view_state/workspace 记录、owner/project/window 隔离、CAS、sync WAL 和现有容量，不引入浏览器正文缓存。集中检查结果见下文和 REVIEW_HANDOFF.md；不能用本文件关闭完整 AC。

每窗口实例新建独立副本；sessionStorage 仅保存最后一次宿主 ACK 的不透明副本 ID。刷新或复制窗口只读该来源，再使用新 ID 写入；没有指针的新窗口通过新增 latest_view 操作一次有界扫描选择当前主体/工作区最新未丢弃位置。来源缺失/格式不支持时保留原记录，不将另一个窗口替换为该来源。查询没有执行或授权副作用，不能重建源对象。

view 内部 schema 1：至多 64 个文档/受支持 surface 标签、当前标签、分栏路径及比例、最后选中会话、至多 128 个文件位置。文本保存 UTF-16 选区 offset 和滚动；原文件变化后由编辑器按当前内容夹取 offset。画布保存 x/y/zoom，沿用现有缩放范围。恢复按当前 workspace 重新构造受支持的内部路由，拒绝任意 URL、路径越界、未来 schema、未知权限字段和超限数据。正文、附件、模型、旧审批、运行权限不在位置记录内；脏稿继续走独立恢复/比较入口。

明确文件/会话深链优先；异步恢复期间的用户操作和新位置优先于旧快照。最近会话按原 ID 读取，源已删除或不可用时明确显示 unavailable 并禁用该源发送；不选成最新会话。New conversation 是明确的新输入位置，记录空 session 后重开仍保留此选择。旧读取不覆盖新会话或工作区。删除失败保持原会话，关联输入先保证宿主备份，已确认草稿保留为孤立副本，不自动重建会话。

位置变化沿用 750ms/5s 备份合并；重复未变通知不新增写入。恢复读不会立刻写一份空快照。备份失败保留当前界面，正式连接呈现既有错误 toast；达到现有容量明确失败，不淘汰未解决输入。原始副本可继续导出；位置记录不混入草稿恢复列表。schema/旧服务不支持时保守报告恢复不可用，不声称已备份。

本功能不恢复 Monaco 完整 undo 栈，不自动加载草稿正文，不把历史监督/运行位置变成执行权限。位置记录的峰值扫描开销、窗口副本增长、Linux/生产链/真实持续观察仍依 DW-07～09 完整验收。
