## 组件与样式

项目没有并用Element Plus、Ant Design、Naive UI等通用组件库；使用Vue、Tailwind、Lucide以及项目内的PageHeader、PageTabs、Dialog和共享按钮/输入/主题样式。Vue Flow、Monaco、CodeMirror是图与文本编辑器的专用组件，继续保留。没有新增依赖。

问题是部分页面自行实现同类头部：内容页22px、聊天15px、执行选择器13px；侧边距28/24/17px，标题距内容顶部也不同。任务页标题下又出现一行左对齐操作栏，设置页标题按钮则单独缩成28px/12px。

| 项目 | r1呈现 |
|---|---|
| 主要页面标题 | 统一PageHeader，18px、600字重、28px行高；桌面同一顶部基线 |
| 侧边距 | 正常内容区24px；内容区不超过600px时16px，按实际面板宽度响应 |
| 任务操作 | 新建/刷新放在标题右侧；复用原面板方法和原禁用条件 |
| 执行页 | 标题/蓝图选择复用PageHeader，保留名称与下拉提示；运行、暂停、停止使用共享按钮 |
| 设置/版本页 | 标题操作使用共享32px/13px控件；补快照创建按钮可访问名称 |
| 局部细节 | 长蓝图名截断可查看完整标题；窄栏操作可换行；图标按钮有一致禁用提示；执行底部标签13px |

欢迎页的入门标题及文件/蓝图工具栏中的文件名属于不同层级，保留其原有用途，不把文档文件名强制变成页面大标题。原IDE分区没有改成新的页面布局。
